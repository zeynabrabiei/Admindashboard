# ✦ Admin Dashboard

A modern, responsive admin dashboard built with React and JavaScript, featuring a clean interface, organized data views, and a professional user experience.

Designed and developed by **Zeynab Rabiei**, Frontend Developer.

## ✨ Overview

Admin Dashboard is a frontend project designed to demonstrate modern React development practices, reusable UI components, and structured application layouts.

The project includes a dashboard overview, product management interface, order and customer pages, authentication UI, and a dedicated settings page — all organized within a consistent admin layout.

## 🚀 Features

* **Dashboard Overview** — A centralized view for dashboard statistics and data visualization.
* **Product Management** — A dedicated interface for viewing product information.
* **Order Management** — An organized view of customer orders and their statuses.
* **Customer Management** — A dedicated customer overview.
* **Authentication UI** — A login page with protected application routes.
* **Settings Page** — A dedicated area for application settings.
* **Data Visualization** — Charts powered by Recharts.
* **Reusable Components** — Modular React components for maintainable code.
* **Responsive UI** — Adaptive layouts for desktop, tablet, and mobile screens.
* **Custom Footer** — A polished footer featuring personal branding and professional links.
* **Client-side Routing** — Page navigation powered by React Router.
* **CSS Modules** — Component-scoped styling to keep styles organized and maintainable.

## ⚙️ Getting Started

### Prerequisites

* Node.js (LTS recommended)
* npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/zeynabrabiei/Admindashboard.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Admindashboard
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
